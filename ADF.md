# Original Amiga disk image

The original ADF is not included in this repository.

Open the [Planet Emulation Commodore Amiga ADF list for the letter
K](https://www.planetemu.net/roms/commodore-amiga-games-adf?page=K), then use the
page filter to find:

```text
Kick Off 2 v1.6e (1990)(Anco)[cr]
```

Download and use the disk image only when permitted by the laws that apply to
you and by the original rights holders.
